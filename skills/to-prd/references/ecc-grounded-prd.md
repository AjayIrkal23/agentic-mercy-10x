# Grounded PRD sections (ECC graft)

1. **Problem** — who has it, how they cope today, evidence it matters.
2. **Goals and non-goals** — measurable outcomes; what this PRD will not do.
3. **Users and scenarios** — the main flows, step by step.
4. **Requirements** — each with an observable acceptance criterion.
5. **Codebase grounding** — the modules, APIs and data it touches (`file:line`), found by
   searching the repo, not assumed.
6. **Risks and open questions** — each with an owner.
7. **Rollout** — flag, migration, metrics to watch.
