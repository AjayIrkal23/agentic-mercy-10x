# Search order (ECC graft)

1. **Repo** — an existing module, helper or pattern that already solves it (jcodemunch).
2. **Docs** — the library's official docs for the installed version (context7).
3. **Web** — only when 1 and 2 have no answer.

Cite the source next to the decision (`file:line`, the doc section, or the URL) so a reviewer
can check it.
