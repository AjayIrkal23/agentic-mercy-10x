# Blueprint output shape (ECC graft)

An architecture answer has five sections, in this order:

1. **Context** — the problem, constraints, existing modules it touches (with paths).
2. **Components** — each new or changed component, its single responsibility, its owner.
3. **Interfaces** — the contracts between components (signatures, payloads, events).
4. **Order** — the build sequence, with what each step unblocks.
5. **Risks** — what could go wrong, how it would show, and the mitigation.
