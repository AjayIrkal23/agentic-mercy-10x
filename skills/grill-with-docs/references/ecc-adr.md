# ADR format and the CONTEXT.md glossary (ECC graft)

## ADR (`docs/adr/NNNN-<slug>.md`)

- **Status:** proposed / accepted / superseded by NNNN.
- **Context:** the forces at play, the constraint that made a decision necessary.
- **Decision:** one paragraph, active voice ("We use X for Y").
- **Consequences:** what gets easier, what gets harder, what we now must do.

Write one only when the choice is hard to reverse, surprising, and a real trade-off.

## CONTEXT.md glossary

One line per domain term: `**Term** — meaning in this project; not to be confused with X.`
When grilling surfaces a fuzzy word, pin it here before it reaches a spec.
