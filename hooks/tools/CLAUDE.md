# `hooks/tools/` — local rules

Standalone hook utilities run by the dispatcher or the doctor, not per-tool links.

| File | Role |
|------|------|
| `link-doctor.py` | fires a synthetic event through every enabled dispatch link; a non-zero exit is `FAIL(rc=N)`, a missing script `FAIL(missing-script)`, non-JSON output from a gate/mutator/exec fails (run by `installer/doctor.py`). Probe children get a throwaway dir for `CLAUDE_HOOK_DOTSTATE_DIR` / `CLAUDE_HOOK_STATE_DIR` / `CLAUDE_HOOK_TELEMETRY_DIR` (unless already set), removed afterwards |
| `state-cleanup.py` | session-start async exec: bounded retention purge of `telemetry/` and `state/` files. `run(base, now, dotstate)` returns `{family: n}`; every family (where, patterns, age) is listed by `python3 hooks/tools/state-cleanup.py --table` (a test keeps it equal to the code). history: `docs/CHANGELOG.md` v4.3.0 § state-cleanup.py |
| `selfheal-daily.py`, `daily_lock.py` | session-start async exec (autonomy WP-D): the once-a-day self-heal, thirteen independent steps in order: `mcp` (re-add, pins, env, alwaysLoad), `plugins` (marketplaces and plugins the manifest gained since install, e.g. `egm@egm`; TokenEconomizer `toolprune` pinned `off`; anything ADDED or INSTALLED forces one re-render, because `claude plugin marketplace add` rewrites `settings.json` and drops template keys such as `autoUpdate: false`), `deps` (base tools, the lightpanda binary, absent CLIs, then the lean-ctx config merge), `plan-tier`, `settings` (also re-renders when the tier's model keys drift, so plan-tier runs first), `oomguard`, `machines-split`, `vendor` (a moved tag reports `WARN(rc=1: <skill>: <repo>@<ref> moved …)`), `workflows`, `library`, `mcp-inventory` (POSIX only, and only where `AGENTIC_MERCY_INVENTORY_WRITER=1` (env or `settings.user.json` env): the tracked file is written on the committing machine alone, never on the replica or a second person's PC), `ponytail-board`, `learning-evolve`. Summary `state/selfheal-daily.json` for the aggregator, non-blocking lock (`daily_lock.py`), log `state/selfheal-daily.log` (no env, no tokens). No-op under `CLAUDE_HOOK_DOCTOR`, pytest (unless `SELFHEAL_DAILY_ALLOW_TEST=1`) and link-doctor's probe; `--dry-run` prints the plan. history: `docs/CHANGELOG.md` v4.3.0 § selfheal-daily.py |
| `memwatch.py` | OOM guard sentinel, run by `claude-memwatch.service`; `--once --dry-run --proc-root <fixture>` to rehearse; units named `claude-test-*` are test scopes and never become kill rows. `load_config(path, total_mb=, local_path=)` resolves the percent lines (warn 15, crit 8, swap rule 22.5, emergency 4) against the watched tree's MemTotal; an MB number in the config file pins its line; then `oomguard.local.json` `tiers` win; the stage-3 announce says `(restored later)`, `(not restorable: tmux missing)` or `(restore off)` (`_stage3_suffix`) |
| `oomguard/` | unit and drop-in templates, `{PY}` / `{HOOKS}` / `{CLAUDE_DIR}` tokens, marker `agentic-mercy oomguard` |
| `instincts.py` | learning (`docs/LEARNING.md`): `evolve` (self-heal step `learning-evolve`; >= 20 new rows per project; one `ollama.chat` per project; `DEFERRED` when the box is down; merge, decay, prune, promote to `instincts/global.jsonl`; `daily_lock` on `state/learning/evolve.lock`), `status [--json]`, `export`, `import <file\|https-url>` (https only, public addresses, no redirects, 1 MB), `lines(cwd, limit, min_confidence)` for `session_notices.instinct_lines` |
| `worktree_audit.py` | `one_line(cwd, budget_ms=400)`: `git worktree list --porcelain`, dirty/stale/`merge-tree --write-tree` conflict prediction against the base branch; read-only; `""` on Windows; the CLI prints the line |
| `retention-report.py` | READ-ONLY report of reclaimable space: plugin versions not in `installed_plugins.json`, `~/.claude/graphify-out`, `projects/` dirs whose newest transcript is older than `--keep-days` and that hold no `memory/`, doc/code indexes whose `source_root` is gone; prints the command to run, deletes nothing. `python3 hooks/tools/retention-report.py [--keep-days N]` |

- None may raise or block a session; set `CLAUDE_HOOK_DOCTOR=1` when
  dry-firing links so disk-writing links no-op.
