# `hooks/tools/` — local rules

Standalone hook utilities run by the dispatcher or the doctor, not per-tool links.

| File | Role |
|------|------|
| `link-doctor.py` | fires a synthetic event through every enabled dispatch link; a non-zero exit is `FAIL(rc=N)`, a missing script `FAIL(missing-script)`, non-JSON output from a gate/mutator/exec fails (run by `installer/doctor.py`). Probe children get a throwaway dir for `CLAUDE_HOOK_DOTSTATE_DIR` / `CLAUDE_HOOK_STATE_DIR` / `CLAUDE_HOOK_TELEMETRY_DIR` (unless already set), removed afterwards |
| `state-cleanup.py` | session-start async exec: bounded retention purge of `telemetry/` and `state/` files. `run(base, now, dotstate)`; families: `state/*.stack.json` and `state/persist-dedup/*.json` >14 d, `state/.tmp-*.swap` >1 d, `hooks/.state/taste-dials/*` >7 d, `hooks/.state/index/*.flush-*.txt` >1 d, `hooks/.state/index/<key>.json` whose `repo_root` is gone >1 d, `hooks/.telemetry/*.suite-gate.json` >14 d; family `orphan-lock`: a `*.json.lock` / `*.jsonl.lock` sidecar (`platform.locked_update` / `append_line`) whose data file is gone, in `state/`, `state/advisory-queue/`, `telemetry/` and `hooks/.telemetry` >1 d (a lock beside a live file and fixed locks such as `selfheal-daily.lock` stay). Test residue is a name with `e2e-` at the start of a segment (`t-e2e-…`, `e2e-repo`), never a session UUID with `…8e2e-…` inside. Test-named sessions (`audit-*`, `ma-{heavy,light}-{live,shadow}-*`, `t<N>-*`, `t-iso-*`, `dryrun-*`, `isg-*`, `t-<32 hex>`) in `state/`, `telemetry/`, `hooks/.state`, `hooks/.telemetry` and fixture stack caches `state/{go,vite,wt}-<8 hex>.stack.json` go after 1 d (matched on the id before the first dot; a real session UUID never matches). `run()` returns `{family: n}`; a run that removed anything appends one `{ts,total,purged}` JSON line to `state/state-cleanup.log` |
| `selfheal-daily.py` | session-start async exec (autonomy WP-D): the once-a-day self-heal. Independent steps `STEPS` = `mcp` (`deps.register_mcps` re-adds a manifest server missing from `~/.claude.json`, then `reconcile_mcp_pins` + `reconcile_mcp_env`; the lock lives in `daily_lock.py`), `deps` (`basetools.ensure_base_tools` = node/claude/uv/gh in `~/.local` on POSIX, git/node/claude/uv/gh in the Windows tools dir through `wintools`; then `install_deps(skip_optional=True)`: installs absent required CLIs, never upgrades, skips `optional` entries so an absent optional dep is not retried every day), `settings` (`selfheal._ensure_settings` when the template/manifest is newer, settings.json is missing, or a command's absolute interpreter path in `statusLine` / `hooks` is no longer a file: `selfheal._stale`), `vendor` (`scripts/vendor_skill.py --all` only when `--all --check` exits 1 = DRIFT; BEHIND is ignored). Stamp + summary `state/selfheal-daily.json` = `{"at","changed","errors","reported"}` (the aggregator reports it once; nothing to say ⇒ `reported` true; unreported lines carry over). When every step failed (`Ctx.steps_ok == 0`) the summary is still written with its errors (`reported:false`) but WITHOUT `at`, so the next session retries (bounded by the lock) instead of waiting 24 h, non-blocking lock `state/selfheal-daily.lock`, log `state/selfheal-daily.log` (names, specs, return codes: no env, no tokens). No-op under `CLAUDE_HOOK_DOCTOR`, under pytest (`PYTEST_CURRENT_TEST` unless `SELFHEAL_DAILY_ALLOW_TEST=1`: a test firing the session-start chain must never heal the LIVE install) and for link-doctor's probe payload (`session_id` `link-doctor`; running `link-doctor.py` by hand does not set the doctor env). `--dry-run` prints the plan and writes nothing |
| `retention-report.py` | READ-ONLY report of reclaimable space: plugin versions not in `installed_plugins.json`, `~/.claude/graphify-out`, `projects/` dirs whose newest transcript is older than `--keep-days` and that hold no `memory/`, doc/code indexes whose `source_root` is gone; prints the command to run, deletes nothing. `python3 hooks/tools/retention-report.py [--keep-days N]` |

- None may raise or block a session; set `CLAUDE_HOOK_DOCTOR=1` when
  dry-firing links so disk-writing links no-op.
